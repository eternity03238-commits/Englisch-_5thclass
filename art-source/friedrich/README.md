# Originale (2048 × 2048 PNG mit Alpha)

Hier liegen die unveränderten Masterbilder. Sie werden nie von der App geladen.
Ablage: `art-source/friedrich/<stufe>/<pose>.png` – das erledigt `tools/import_friedrich.py` automatisch.

Neue Bilder: in einen Ordner legen, Dateinamen `friedrich_<stufe>_<pose>.png`, dann
`python3 tools/import_friedrich.py <ordner> --repo .`
